# 再利用スキル：日本語学習サイト制作

`build-learning-site-ja`は、学習サイトを「要点 → 図解 → 短い本文ブロック」で制作・改修するCodex向けスキルです。Jev以外のテーマにも使えます。

## Codexのユーザー共通スキルとして配置する

このリポジトリをローカルに取得してから、リポジトリのルートで実行します。

```bash
bash skills/build-learning-site-ja/scripts/install-global.sh
```

配置先は`$HOME/.agents/skills/build-learning-site-ja`です。既存の同名フォルダーは上書きしません。同じ内容が配置済みなら変更せず終了します。一般的な旧配置先`$HOME/.codex/skills`と`$CODEX_HOME/skills`の同名フォルダーも確認し、存在すれば停止します。他の設定やスキルには変更を加えません。

インストーラーはローカルファイルの配置とコピー内容の一致を確認します。稼働中のCodexが認識したことまでは確認しません。スキルが表示されない場合はCodexを再起動し、`$build-learning-site-ja`で呼び出してください。

## 使用例

```text
$build-learning-site-ja
Cloudflare Workersを初めて学ぶ人向けの日本語学習サイトを作ってください。
公式ドキュメントを確認し、入門から応用まで、要点・図解・短いブロックで理解できる構成にしてください。
まずサイト制作とローカル検証まで行い、公開操作はまだしないでください。
```

GitHubへの保存と、利用者のMacへのグローバル配置は別の操作です。このリポジトリに追加しただけでは、各Macに自動インストールされません。

## 内容

スキル本体、Codex向け表示メタデータ、記事設計と実装・検証のガイド、章テンプレート、出典・検証状況の台帳、Markdown監査スクリプト、上書きしない配置スクリプトを含みます。元のサイト本文やビルド設定は変更していません。

## 作成時の検証

Linuxの隔離環境で、メタデータ・内部参照・JSON・シェル構文を検証し、監査と配置スクリプトに対する20件の動作確認を実施しました。配置テストには一時的なHOMEを使い、新規配置、同一内容での再実行、上書き拒否、旧配置先との競合、空白を含むパスを確認しました。

利用者のMacでの実行、Codexによる認識、新しいエージェントによるサイト制作の通し実行は未検証です。監査スクリプトは記事の構造を検査するもので、事実の正しさやURLの到達可能性を保証しません。
