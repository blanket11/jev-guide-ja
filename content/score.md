:::brief Scoreは、段階ごとの確率を使った評価値
- **基準は順番に並べる。** 3段階なら番号は0・1・2です。
- **返る値は小数にもなる。** 段階番号を確率で重み付けした値です。
- **平均だけでは不十分。** 同じ平均でも、分布が違う場合があります。
:::

:::flow この教材の3段階：低い側から高い側へ
0｜落ち着いている | 不満の表明なし
1｜不満がある | 穏やかな表現で不便を訴える
2｜強い怒りがある | 強い不満を明確に表す
! 段階の順序を示す図です。気持ちがこの順に変化する図ではありません。
:::

## 「どれくらいか」を、言葉で段階にする
Scoreでは、低い側から高い側へ並べた基準を`criteria`に渡します。2段階以上が推奨され、確認時点のAPIは最大10段階を受け付けます。返る数値は0から始まる段階番号に対応します。[公式：Score](https://docs.typesafe.ai/primitives/score)

```json
{
  "type": "score",
  "instructions": "問い合わせの文章に表れている不満の強さを評価してください。",
  "criteria": [
    "不満の表明がなく、落ち着いて状況を説明している",
    "不便さや不満を表しているが、穏やかな表現である",
    "強い怒りや、繰り返しの不満を明確に表している"
  ]
}
```

この教材では段階0・1・2の3つです。返答の`legend`は段階番号と説明の対応、`probabilities`は各段階の確率、`score`は確率を使った重み付きの値です。[公式：Score](https://docs.typesafe.ai/primitives/score)

## 1.5は「半分怒っている」ではない
- 段階0の確率が0、段階1が0.5、段階2が0.5なら、計算は`0 × 0 + 1 × 0.5 + 2 × 0.5 = 1.5`です。
- 段階1と2の間に分布していることを表します。
- 実際の人間の感情を、精密に1.5と測定したわけではありません。

同じ平均でも分布が違うことがあります。段階1だけに確率が集まる場合と、段階0・2に半分ずつ分かれる場合は、どちらも平均1ですが意味が異なります。平均値だけでなく分布も確認する理由です。

## このデモで分かること
スライダーはモデルへの入力ではなく、説明用の重みです。合計で割って確率に直し、段階番号との積を足しています。Jevの推論や`confidence`の計算は再現していません。

## 1つの軸だけを測る
- 「すぐ対応すべきで、ユーザーの不満も強く、改善効果も高い」という基準は、複数の軸を混ぜています。
- 不満の強さ、機能への影響、対応による効果は分けて質問し、後からコードで組み合わせます。
- 複合評価は[複数スコアの合成](composite.html)で扱います。

:::warning Scoreを数値の抽出器にしない
- 「年齢は0歳・50歳・100歳のどの間か」と聞いてscoreから正確な年齢を復元する、といった利用には向きません。
- 公式も、段階間の補間を厳密な数量の復元に使わないよう注意しています。 [公式：Jev 1.13 jaggedness](https://docs.typesafe.ai/model-jaggedness/jev-1.13)
:::

:::answer 確認問題：3段階のScoreの最大値は3ですか？
いいえ。段階番号は0・1・2なので最大値は2です。4段階なら0〜3になります。
:::
